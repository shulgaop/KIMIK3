# Инструкция: отчёт о походе из фото и видео

Полный путь от установки Python до готовой карты маршрута.
Инструкция для Windows 10/11, опыт программирования не нужен.

---

## Самый простой способ: установщик в один клик

1. Положите в папку с фото и видео **два файла**: `hike_report.py`
   и `УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat`. Если есть GPX-треки — тоже в эту папку.
2. Дважды кликните **`УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat`**. Он сам:
   - проверит Python и, если его нет, скачает и установит
     (через winget или установщик с python.org);
   - доустановит недостающие библиотеки (уже установленные пропустит);
   - запустит обработку и покажет результат.

При первом запуске нужен интернет и 5–10 минут времени. Дальнейшие
запуски — просто двойной клик, установка пропускается.

> Windows может показать предупреждение «Система SmartScreen
> предотвратила запуск...» — это стандартная реакция на .bat-файлы.
> Нажмите «Подробнее» → «Выполнить в любом случае».

**Шаги 1–2 ниже — запасной вариант**, если автоматика не сработает
или вы хотите установить всё вручную.

---

## Шаг 1. Установка Python

1. Откройте сайт **https://www.python.org/downloads/**
2. Нажмите жёлтую кнопку **Download Python 3.x** — скачается установщик.
3. Запустите скачанный файл.
4. **Очень важно:** в первом окне установщика внизу поставьте галочку
**«Add python.exe to PATH»** — без неё команда `python` работать не будет.
5. Нажмите **Install Now** и дождитесь окончания.

### Проверка установки

1. Нажмите клавиши **Win + R**, введите `cmd`, нажмите Enter — откроется
чёрное окно командной строки.
2. Введите команду и нажмите Enter:

```javascript
   python --version
```

3. Должно появиться что-то вроде `Python 3.12.4`.

**Если пишет «python не является внутренней или внешней командой»** —
галочка PATH не была поставлена. Запустите установщик ещё раз,
выберите **Modify → Next →** галочка **Add Python to environment
variables **→ **Install**. Либо удалите Python и установите заново,
не забыв галочку.

> Альтернатива: Python можно установить из магазина **Microsoft Store**
> (найдите «Python 3.12») — там PATH настраивается автоматически.

---

## Шаг 2. Установка библиотек

В том же окне командной строки выполните одну команду:

```javascript
python -m pip install pillow folium openpyxl reverse-geocoder pyosmogps imageio-ffmpeg
```

Дождитесь окончания (пойдут строки про скачивание — это нормально,
займёт 1–3 минуты).

> `imageio-ffmpeg` нужен, чтобы у видео на карте были превью-кадры
> (как миниатюры в Проводнике Windows). Без него всё остальное будет
> работать, но маркеры видео останутся без картинок.

**Если у вас iPhone и фото в формате HEIC**, выполните дополнительно:

```javascript
python -m pip install pillow-heif
```

> Зачем `python -m pip`, а не просто `pip`? Так библиотеки гарантированно
> встанут в тот же Python, которым вы будете запускать скрипт.

## Шаг 3. Подготовка папки с файлами

1. Скопируйте **оригиналы** фото и видео в одну папку, например
`D:\Поход`. Подпапки внутри не страшны — скрипт заглянет и в них.

⚠️ Используйте файлы, скопированные напрямую с телефона/камеры/карты
памяти. Фото, пересланные через WhatsApp или Telegram, **лишены
координат** — мессенджеры вырезают их при отправке.

2. Положите в эту же папку файл **`hike_report.py`**.

3. **Если есть записанный трек похода** (с часов, навигатора, приложений
Strava, Maps.me, Organic Maps, Locus и т.п.) — экспортируйте его в формат
**GPX** и положите файл `.gpx` в ту же папку. Скрипт подхватит его
автоматически и привяжет к треку все фото и видео без координат —
по времени съёмки. Это спасёт материалы с DJI Action 6, снятые без
GPS-пульта, и фото без геометок. GPX-файлов может быть несколько
(например, один на каждый день) — скрипт объединит их все.

---

## Шаг 4. Запуск скрипта

**Способ А (проще всего):**

1. Откройте папку с фото в Проводнике.
2. Кликните в адресную строку Проводника (где путь `D:\Поход`),
введите `cmd` и нажмите Enter — командная строка откроется сразу
в этой папке.
3. Введите:

```javascript
   python hike_report.py
```

4. Нажмите Enter и ждите. Скрипт будет показывать прогресс:
какой файл обрабатывается и найдены ли в нём координаты.

### Вопросы при запуске

Перед обработкой скрипт задаст 2–3 вопроса (Enter = вариант
по умолчанию):

**1. Откуда брать координаты?**
- `1` — из геоданных файлов; где их нет — по времени съёмки
  из трека и планового маршрута (по умолчанию);
- `2` — только по времени съёмки из трека/плана
  (геоданные в файлах игнорируются — полезно, если координаты
  в файлах неточные или вы хотите единый маршрут строго по треку);
- `3` — только из геоданных файлов (трек не использовать).

**2. Видео DJI** (спрашивается, только если такие видео есть и выбран
комбинированный режим): телеметрия / трек / и то и другое.

**3. Офлайн-карта**: скачать локальные тайлы (карта будет работать без
интернета) или ограничиться онлайн-подложками.

**Способ Б (из любого места):**

```javascript
python "D:\Поход\hike_report.py" "D:\Поход"
```

(первый путь — к скрипту, второй — к папке с фото)

## Шаг 5. Что получится

После окончания в папке появятся:

| Файл | Что это |
| --- | --- |
| **карта_похода.html** | Интерактивная карта — открывается двойным кликом в браузере, удобна и на телефоне. Маршрут по дням разными цветами, маркеры с превью (у фото — снимок, у видео — кадр с 1-й секунды), треки DJI пунктиром, загруженный GPX-трек — чёрным пунктиром. Панель слоёв свёрнута — открывается кнопкой в правом верхнем углу |
| **отчёт_похода.xlsx** | Таблица Excel: файл (кликабельно), день, дата/время, координаты (клик открывает точку в Google Maps), название местности |
| **файлы_без_геометок.txt** | Список файлов, в которых координат не оказалось |
| **tiles_offline/** | Локальные тайлы карты — с ними карта работает без интернета |

В конце работы скрипт выведет сводку: сколько файлов обработано,
у скольких нашлись координаты, сколько дней в маршруте.

## Настройки (необязательно)

В начале файла `hike_report.py` есть блок с настройками — его можно
править в любом текстовом редакторе (например, в Блокноте):

```python
DJI_TIMEZONE_OFFSET = 5     # часовой пояс для видео DJI (Фаны/Таджикистан = 5)
GPX_TIMEZONE_OFFSET = 5     # часовой пояс для GPX-трека (время там — UTC)
TRACK_MAX_GAP_MIN = 30      # привязывать фото к треку, если точка трека
                            # не дальше этих минут от времени съёмки
OFFLINE_MAP = True          # False — не скачивать офлайн-тайлы
OFFLINE_MIN_ZOOM = 10       # минимальный масштаб офлайн-карты
OFFLINE_MAX_ZOOM = 14       # максимальный масштаб (больше = детальнее,
                            # но тяжелее)
```

**Как работает привязка к треку:** у фото берётся дата/время съёмки,
ищется ближайшая по времени точка трека — её координаты присваиваются
фото. В таблице в столбце «Источник» такие строки помечены
`по треку (±N мин)` — это погрешность привязки. Сам трек на карте
рисуется чёрным пунктиром отдельным слоем «GPS-трек (GPX)».

Если среди GPX-файлов есть **плановый маршрут** (трек без меток времени,
например скачанный из интернета), он работает двояко:

1. **Рисуется на карте** отдельным слоем «Плановый маршрут (GPX)»
   зелёным пунктиром, а путевые точки (лагеря, перевалы) — зелёными
   кружками с подписями;
2. **Заполняет пропуски записанного трека**: если за какой-то день трек
   не сохранился, скрипт оценивает позицию фото интерполяцией —
   концы соседних записанных треков становятся опорными точками на
   плановом маршруте, а фото между ними расставляются пропорционально
   времени. Такие строки помечены в таблице как `по плану (оценка)` —
   это приблизительная позиция, а не точная. Отключается настройкой
   `PLAN_INTERPOLATION = False`.

**Важно про часовой пояс:** в GPX время всегда в UTC, а в фото —
локальное. Для Фанских гор (Таджикистан) пояс = 5, уже выставлено
в скрипте. Если привязка «не срабатывает» или точки съезжают —
проверьте `GPX_TIMEZONE_OFFSET` (для Москвы было бы 3).

## Корректировка позиций на карте (вручную)

Если какая-то точка стоит не там (например, оценка «по плану»
неточна, или вы просто помните, где был сделан кадр):

1. Откройте `карта_похода.html` — **все маркеры перетаскиваются**:
   зажмите маркер мышью и перенесите на правильное место.
2. После первого перетаскивания слева внизу появится кнопка
   **«Скачать правки (N)»**. Когда закончите — нажмите её: скачается
   файл `правки_координат.json`.
3. Положите этот файл в папку со скриптом и фото и **запустите
   скрипт ещё раз**. Поправки применятся ко всему: маркерам, линиям
   маршрута, таблице Excel (столбец «Источник» покажет «вручную»)
   и ссылкам на Google Maps.

Файл правок можно пополнять: открыли карту, подвинули ещё маркеры,
скачали — новые правки заменят старые для тех же файлов, остальные
сохранятся.

## Частые проблемы

**«python не является внутренней или внешней командой»**
→ Python установлен без галочки PATH. См. конец шага 1.

**«ModuleNotFoundError: No module named 'folium'»** (или другое имя)
→ Библиотека не установлена. Выполните:
`python -m pip install folium` (подставьте имя из ошибки).

**Офлайн-карта серая / с надписями «API KEY REQUIRED»**
→ Удалите папку `tiles_offline` и запустите скрипт заново —
тайлы скачаются с рабочего источника (Esri).

**Слои OpenStreetMap / OpenTopoMap показывают «403 Access blocked»**
→ Это политика их серверов, на ваши данные не влияет. Пользуйтесь
слоями «Карта (Esri Topo)», «Спутник (Esri)» или офлайн-картой.

**Видео с DJI Action 6 — «нет GPS»**
→ У камеры нет встроенного GPS. Координаты есть, только если при съёмке
был подключён GPS Bluetooth-пульт DJI (или приложение, передающее GPS
с телефона). Если пульта не было — положите в папку GPX-трек похода:
скрипт привяжет видео к треку по времени съёмки.

**Фото не привязались к треку, хотя GPX лежит в папке**
→ Проверьте три вещи: 1) трек действительно записан в дни похода
(в сводке скрипт печатает период трека); 2) `GPX_TIMEZONE_OFFSET`
соответствует поясу похода; 3) разрыв между временем фото и ближайшей
точкой трека не больше `TRACK_MAX_GAP_MIN` (по умолчанию 30 минут —
можно увеличить).

**Много фото «без геометок»**
→ Скорее всего, это копии из мессенджеров. Замените их оригиналами
с телефона и запустите скрипт ещё раз — он всё пересчитает.

**Загрузка тайлов оборвалась на середине**
→ Просто запустите скрипт снова: скачанное сохраняется, загрузка
продолжится с места обрыва.

## Перенос карты на другой компьютер

Скопируйте **вместе**: `карта_похода.html` + папку `tiles_offline`.
Тогда карта откроется где угодно, даже без интернета.
Файл `отчёт_похода.xlsx` самодостаточен, но кликабельные имена файлов
работают, только если таблица лежит рядом с фото.

---

## Как отправить карту другу, чтобы она открылась

**Главное правило:** один файл `карта_похода.html` **не содержит** саму
карту-подложку — он подгружает её из интернета или из папки
`tiles_offline`, лежащей рядом.

**Способ 1 (надёжный):** упакуйте в zip-архив **вместе**:
`карта_похода.html` + папку `tiles_offline` (она появится, если при
запуске на вопрос об офлайн-карте ответить Enter). Друг распаковывает
архив и открывает html — карта работает даже без интернета.

**Способ 2:** если отправляете только html-файл, у получателя должен
быть интернет. Подложка подгрузится онлайн.

Важные мелочи:

- Открывать файл нужно **в браузере** (Chrome, Edge, Safari),
  а не во встроенном просмотрщике мессенджера — там JavaScript
  не работает, и карта будет пустой. Если друг открывает файл прямо
  из Telegram/WhatsApp — пусть сначала сохранит его, а потом откроет
  через браузер.
- Карта теперь «самолечащаяся»: если подложка не загрузилась
  (нет интернета или нет папки `tiles_offline` рядом), она автоматически
  переключается на другой слой, а если не удалось совсем — покажет
  подсказку, что делать.
