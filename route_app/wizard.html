    Отчёт о пройденном походе
    
  
    Записанный трек с часов + ваше описание → отчёт в формате категорийного похода
  (статистика дней из трека, события из описания). Работает с текущим проектом: не выбран —
  выбрать можно на вкладке «Мастер», шаг 1.
    
  
  
  
  
  
  
  
    

    

    
  
    Дополнить отчёт
    
  
    Текст любого размера и/или файл (TXT, PDF, DOCX — текст распознаётся и попадёт в отчёт).
  Абзац с префиксом «день 3:» попадёт в третий день, без префикса — в общие заметки.
  После добавления отчёт пересобирается.

    Быстрый старт за 5 минут
    
  
      
    
    1. Мастер → шаг 1: введите название похода и даты → «Создать проект».
      2. 
    
    2. Шаг 2: загрузите программу (PDF/DOCX) или вставьте текст → «Прочитать программу».
        Приложение само найдёт даты, дни и точки — проверьте их в спойлере и сохраните.
        Туда же — плановый GPX-трек, а после похода — записанный трек с часов.
      3. 
    
    3. Дальше жмите большие зелёные кнопки по порядку: Анализ → Погода →
        Гид (ИИ) → Документы → Фото. Пройденные шаги отмечаются галочкой ✓.
      4. 
    
    4. Шаг «Результат»: «Скачать всё одним zip» — весь комплект (гид, карта, календарь,
        чеклист, аудиогид, фотоотчёт) в одном архиве.
      5. 
  
    

    


    
  
    Что делает каждый шаг мастера
    
  
    
    
    ШагЧто загрузитьЧто получится
    
    
    2 · ПрограммаPDF/DOCX/TXT с описанием или текст; плановый GPX; трек с часов (после похода)
        программа.txt, черновик points.json
    
    
    3 · Анализtrack.gpx + точкианализ.json — км, высоты, уклоны, азимуты
    
    
    4 · Погодадаты + точкиПогода.md (прогноз/климат/факт), Световой_день.md (рассветы, Луна)
    
    
    5 · Гид (ИИ)ключ OpenRouterГид.md + Гид.html, аудиотексты → mp3, факты из Википедии/OSM
    
    
    6 · Документы—маршрут.kml, календарь.ics, Чеклист.html, Аптечка.html, Деньги.md
    
    
    7 · Результат—zip всего проекта
    
  
    
  
    Фото и видео живут в отдельной вкладке «Фотоотчёт» (сортировка по дням, фотометки к аудиогиду, карта и таблица похода с настройками привязки).
    
  
    Совет: в шаге 5 сначала «🔎 Найти факты», потом «Сгенерировать путеводитель» — гид будет с факт-блоками и источниками.
    

    


    
  
    Вкладка «Отчёт» — после похода
    
  
      
    
    1. Загрузите записанный трек с часов (GPX с таймстемпами) — дни, километры и наборы посчитаются сами.
      2. 
    
    2. Добавьте описание текстом или файлом. Абзацы «День 2. …» попадут во второй день, остальное — в общие заметки.
      3. 
    
    3. «Собрать отчёт» → Отчёт.html в формате отчёта о категорийном походе.
      4. 
    
    4. Дополняйте: поле принимает текст любого размера и файлы (TXT/PDF/DOCX — текст распознаётся).
        Абзац «день 3: …» — в третий день. Отчёт пересобирается автоматически.
      5. 
  
    
  
    Погода-факт (шаг 4 после дат похода) автоматически добавит в отчёт таблицу реальной погоды.
    

    


    
  
    Вкладка «Обучение»
    
  
      
    
    • Правила генерации — короткие проверяемые правила для ИИ («числа в аудиотекстах прописью», «уклоны только из анализа»).
      • 
    
    • База примеров — эталонные фрагменты выдачи: на них ИИ учится оформлять разделы.
      • 
  
    
  
    Всё хранится локально в route_app/learn/ и не попадает в git.
    

    


    
  
    Ключ OpenRouter (бесплатно)
    
  
      
    
    1. Откройте openrouter.ai/keys → Sign up (Google) → «Create Key».
      2. 
    
    2. Вставьте ключ в поле шага 5 — он сохранится локально (в git не попадает).
      3. 
    
    3. Бесплатные модели — в списке (по умолчанию самая сильная). Платные — впишите id
        (например openai/gpt-5) при платной подписке OpenRouter.
      4. 
  
    
  
    Дневной лимит бесплатных моделей ~50 запросов. Исчерпали — дождитесь следующего дня или используйте платную модель.
    

    


    
  
    Фото и видео: вкладка «Фотоотчёт»
    
  
      
    
    • На телефоне включите геометки: iPhone — Настройки → Конфиденциальность → Службы геолокации → Камера;
        Android — в камере «Сохранять геопозицию». Фото из мессенджеров присылайте «файлом» — иначе EXIF вырезается.
      • 
    
    • Записывайте трек на часах/навигаторе (Garmin, Suunto, Amazfit → экспорт GPX) и загрузите его во вкладке «Фотоотчёт» —
        фото без GPS встанут на маршрут по времени съёмки.
      • 
    
    • Нет записи за день — позиция оценивается по плановому треку и честно помечается «по плану (оценка)»
        (отключается в настройках привязки).
      • 
    
    • Настройки привязки: часовой пояс похода (в GPX время в UTC! Фаны = UTC+5, Москва = UTC+3),
        макс. разрыв фото↔трек (минуты), офлайн-тайлы карты (долго качаются, зато карта работает без интернета).
      • 
  
    

    


    
  
    Открыть мастер с телефона
    
  
      
    
    1. На компьютере: python webapp.py --host 0.0.0.0
      2. 
    
    2. В консоли появится адрес вида http://192.168.x.x:8077 — откройте его на телефоне (та же Wi-Fi сеть).
      3. 
    
    3. Готовые Гид.html, Чеклист.html и Отчёт.html работают офлайн — скопируйте в телефон перед выездом.
      4.

    Частые проблемы
    
  
    
    
    СимптомРешение
    
    
    «Ключ OpenRouter отклонён (401)»Проверьте ключ в шаге 5 или создайте новый на openrouter.ai/keys
    
    
    «HTTP 429 / rate-limited»Дневной лимит бесплатных моделей исчерпан — подождите до завтра или впишите платную модель
    
    
    Погода пишет «Open-Meteo недоступен»Проверьте интернет; скрипт сам повторяет запрос 3 раза
    
    
    Фото в «Неразобранном»В файле нет EXIF (мессенджер вырезал) — просите оригиналы «файлом»
    
    
    «Бинарный .doc не читается»Пересохраните документ в Word как .docx
    
    
    Порт 8077 занятpython webapp.py --port 8080
    
    
    Нужен офлайн-аудиогид«Озвучить mp3» (шаг 5) → Аудиогид.zip; нужен edge-tts из requirements
