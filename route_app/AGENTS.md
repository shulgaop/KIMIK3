# Проект: Генератор путеводителей горных походов (route_app)

Ты — кодовый агент Kimi Code. Проект строит приложение, которое по программе похода
(PDF), GPX-треку, билетам и датам производит полный комплект документов похода:
MD-гид, офлайн HTML-гид, аудиогид mp3, GPX/KML с точками аудиогида, ICS-календарь,
интерактивные чеклисты, снимок СТАТУС.

## Читай перед работой (порядок обязателен)
1. `СТАТУС_<Маршрут>.md` активного проекта (если есть) — что уже сделано и какие
   решения НЕ откатывать.
2. `../Инструкция_генерация_горных_маршрутов.md` — методика и чек-лист выдачи.
3. `ТЗ_приложение_генератор_горных_маршрутов.md` — скоуп (MVP: F1–F6, F9).

## Контракт качества (нарушать нельзя)
- **Вычисления — только кодом**: км по гаверсинусу, высоты из ele, проекции точек
  на трек, азимуты плеч, градиенты окном 300–500 м. См. `scripts/gpx_analyze.py`.
- **KML-валидация после каждой генерации**: XML парсится; все координаты точек и
  линий в bbox региона (ловит перепутанные lat/lon); ID стилей латинские без
  пробелов; каждый styleUrl имеет Style id; внешние иконки запрещены.
- **Погода честная**: >10–14 дней до дат — климат + дата перепроверки, без выдумок;
  после похода — факт-наблюдения для отчёта.
- **Аудиогид**: тексты с числами прописью, 40–80 с/трек, голос ru-RU-DmitryNeural
  (настраивается), проверка ffprobe каждого файла, zip; точки 🎧 дописываются в GPX.
- **HTML-гид**: один самодостаточный файл, инлайн CSS/JS, системные шрифты с
  кириллицей, якорное оглавление, SVG-профиль высот, @media print, мобильная вёрстка.
- **СТАТУС**: обновляется после КАЖДОГО изменения выдачи (не в конце сессии).

## Рабочий процесс
1. Понять задачу из ТЗ/снимка; незакрытые вопросы — список «открытых вопросов» в ТЗ.
2. Менять код в `routegen/`; общие вычисления выносить в переиспользуемые функции.
3. Проверять себя на эталоне Фанов: 60 км, Чимтарга 4740 м, уклоны 30–40°,
   15 аудиотреков, bbox (38.9–39.6N, 67.9–68.5E).
4. В ответе: что изменено, какие файлы, как проверено.

## Команды
```
python3 scripts/gpx_analyze.py track.gpx --points points.json   # анализ трека
python3 scripts/make_kml.py track.gpx out.kml --bbox S N W E    # KML + валидация
python3 scripts/make_ics.py events.json out.ics                 # календарь
python3 scripts/tts_audioguide.py texts.json out/ --rate -5%    # аудиогид
```
