# Промт для Kimi Code — Trek Fourge: библиотека путешествий

Скопируй текст ниже линии в новый чат Kimi Code в репозитории KIMIK3.
Промт описывает готовую реализацию и может использоваться для переноса фичи
в другую ветку или для её расширения.

---

Проект: Trek Fourge. Сначала прочитай корневой `AGENTS.md`,
`route_app/AGENTS.md`, `routes/japan/AGENTS.md` и `routes/japan/CONTEXT.md`.
Работай в `feature/japan-guide`, не перезаписывай чужие незакоммиченные
изменения. Палитру «полевого журнала», автономность HTML и аудиофайлы не меняй.

## Задача

Добавь в `route_app/wizard.html` вкладку **«Библиотека путешествий»**.
Нужна работающая реализация, а не концепт. Приложение должно находить и
открывать опубликованные веб-гиды KIMIK3, используя только два JSON-контракта.
Внутренности HTML гидов, их генераторы и аудио не изменяются.

## Источники данных

1. Реестр `guides.json`, схема `kimik3-guides-registry/1`:
   `id`, `title`, `url`, `manifest`, `dates {start,end,tz}`, `gate`.
2. Манифест по URL из записи, схема `kimik3-guide-manifest/1`:
   `entry`, `gate`, `days[]` (`day`, `title`, `page`, `audio[]`),
   `files` и `build {commit,utc}`.

Стандартный источник:
`https://raw.githubusercontent.com/shulgaop/KIMIK3/main/guides.json`.
Сделай URL настраиваемым с восстановлением стандартного значения.
Новый гид должен появляться добавлением записи в реестр без правки приложения.
Все пути манифеста разрешай относительно `url` через `new URL`, включая UTF-8
и пробелы. Разрешай только HTTP(S), не вставляй данные JSON в HTML без
экранирования.

## Обязательный сценарий

- Карточки: название, диапазон дат, IANA timezone, статус «Предстоит» /
  «Сейчас в поездке» / «Завершено», вычисленный кодом от текущей даты в поясе
  маршрута.
- Сводка из манифеста: число дней, аудиотреков и файлов комплекта.
- «Открыть путеводитель» ведёт на `url + entry`; «Дни и файлы» раскрывает
  страницы дней, аудио, KML, ICS, чеклист, бюджет, бронирования и источники.
- Поиск учитывает название поездки и названия дней; отдельный фильтр показывает
  предстоящие, текущие и завершённые поездки.
- Кнопка «Обновить» заново загружает реестр и все манифесты. Показывай дату
  последней копии и сведения `build.commit` / `build.utc`. Если commit изменился
  с прошлого просмотра карточки, отметь новую сборку.

## Приватность и офлайн

- При `gate` покажи подсказку, что кодовое слово вводится на сайте гида.
  Не запрашивай, не передавай и не сохраняй слово в приложении.
- Сохраняй последний валидный реестр и манифесты в localStorage вместе с датой.
  При ошибке сети показывай последнюю копию и честное предупреждение.
- Без сети отключай ссылки, которые раньше не открывались. Для ранее открытых
  ссылок указывай, что доступ зависит от HTTP-кэша браузера; не обещай офлайн
  доступ только потому, что сохранён манифест.
- Обрабатывай запрет localStorage без падения всего приложения.

## Ошибки и совместимость

- Таймаут запроса, HTTP-ошибка и битый JSON показываются понятным текстом.
- Ошибка одного манифеста остаётся в его карточке и не скрывает остальные гиды.
- При ошибке обновления используй прежний кэш манифеста, не затирай его до
  успешной замены.
- Неверная структура записи или полей `days` / `files` не должна ронять список.
- При другой мажорной версии манифеста не разбирай его поля: покажи предупреждение
  и оставь прямую ссылку на гид. Другая мажорная версия реестра — явная ошибка
  с возможностью показать предыдущий кэш.
- Предусмотри загрузку, пустой реестр, отсутствие результатов поиска и состояние
  без сети и кэша.

## UX и ограничения

- Сохрани существующие вкладки, API, сценарии мастера и дизайн-систему.
- На 390 px карточки в одну колонку, поля не меньше 16 px, без горизонтального
  переполнения; на 1440 px используй аккуратную сетку.
- Работают Enter, видимый фокус, мобильное меню и Escape. Не добавляй зависимости,
  CDN, фреймворки или парсинг HTML гидов.
- Не меняй MP3, манифест Японии и опубликованный сайт ради этой фичи.

## Проверки

1. Реальный гид Японии: даты 02–10.09.2027, 9 дней, 25 аудиотреков, 6 файлов.
2. Раскрытие дней, наличие аудио и комплекта; поиск, пустой результат и фильтры.
3. MP3 отвечает `audio/mp3`, страница дня — `text/html`; переходы ведут на
   правильные UTF-8 URL. Кодовое слово вводится только на сайте гида.
4. Временный реестр с исправным гидом и второй записью с битым JSON: исправная
   карточка остаётся, ошибочная показывает состояние ошибки.
5. Программные проверки извлечённого из итогового HTML кода: обе схемы, битый
   JSON, мажорные версии, неверные поля, URL, статусы дат, офлайн-кэш и ссылки.
6. Браузер 1440 и 390 px, мобильное меню, клавиатура, отсутствие переполнения.
7. `python3 -m pyflakes scripts/*.py webapp.py` — чисто;
   `python3 scripts/test_regression.py` — 14/14.
8. Для Японии запусти локальный сервер `python3 -m http.server 8123 --directory
   routes/japan/generated`, затем `cd routes/japan && python3 data/check_links.py`:
   0 отсутствующих файлов и 0 битых HTTP. Проверь живой URL гида.
9. Удали временные файлы и останови тестовые серверы.
