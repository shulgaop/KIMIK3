# Промт для Kimi Code — Track Fourge: доступ к опубликованным гидам

Скопируй текст ниже линии в новый чат Kimi Code в проекте Track Fourge.
Промт самодостаточен: контракт, файлы-образцы и критерии приёмки включены.

---

## Задача

Добавь в приложение Track Fourge раздел **«Мои гиды»**: приложение должно
находить, показывать и открывать опубликованные веб-гиды маршрутов,
сгенерированные конвейером KIMIK3 (первый — «Япония 2027», дальше будут
новые маршруты по тому же контракту). Гиды живут на GitHub Pages и
обновляются автодеплоем; приложение не должно ничего знать о внутренностях
сайта — только два JSON-контракта ниже.

## Контракт интеграции (уже действует)

**1. Реестр гидов** — `guides.json` в корне репозитория маршрутов
(схема `kimik3-guides-registry/1`):

```json
{
 "schema": "kimik3-guides-registry/1",
 "guides": [
  {
   "id": "japan-2027",
   "title": "Япония 2027 · Фудзи и Кумано Кодо",
   "url": "https://shulgaop.github.io/KIMIK3/",
   "manifest": "https://shulgaop.github.io/KIMIK3/гид.json",
   "dates": {"start": "2027-09-02", "end": "2027-09-10", "tz": "Asia/Tokyo"},
   "gate": "sha256-localstorage"
  }
 ]
}
```

Источник реестра для приложения: raw-URL файла `guides.json`
(`https://raw.githubusercontent.com/shulgaop/KIMIK3/main/guides.json` —
перепроверь ветку) либо настраиваемый список URL в настройках приложения;
обновление — pull-to-refresh, без хардкода единственного гида.

**2. Манифест гида** — `<url>гид.json` (схема `kimik3-guide-manifest/1`):

```json
{
 "schema": "kimik3-guide-manifest/1",
 "id": "japan-2027",
 "title": "Япония 2027 · Фудзи и Кумано Кодо",
 "dates": {"start": "2027-09-02", "end": "2027-09-10", "tz": "Asia/Tokyo"},
 "entry": "Гид.html",
 "gate": {"type": "sha256-localstorage"},
 "days": [
  {"day": 2, "title": "День 2 · Фудзи · …",
   "page": "slice-day2/выходные/Гид.html",
   "audio": [{"title": "5-я станция",
              "file": "slice-day2/выходные/аудио/01 — 5-я станция.mp3",
              "bytes": 294480}]}
 ],
 "files": {"kml": {"file": "маршрут.kml"}, "ics": {"file": "маршрут.ics"},
           "bookings": {"file": "Бронирования.html"},
           "sources": {"file": "Источники.html"}},
 "build": {"commit": "04d855b", "utc": "…"}
}
```

Все пути в манифесте — относительные от корня сайта гида (`url` + путь,
UTF-8, пробелы URL-кодировать). Схема версионируется строкой `schema`:
при несовпадении мажорной версии — показать гид просто ссылкой, не падать.

## Что сделать в приложении

1. **Экран «Мои гиды»**: список из реестра — название, даты поездки,
   статус «до/идёт/прошла» (вычисляется кодом от `dates`, пояс из `tz`).
2. **Карточка гида**: из манифеста — список дней с названиями, кнопки
   «Открыть день», «Аудио дня», файлы комплекта (KML → экспорт в
   офлайн-карты, ICS → добавить в календарь, Бронирования/Источники →
   открыть страницу).
3. **Открытие гида**: во встроенном браузере приложения (или системном —
   выбор в настройках). У гида есть экран кодового слова
   (`gate: sha256-localstorage`): слово хранится у пользователя,
   приложение его НЕ хранит и НЕ передаёт; покажи подсказку «введите
   кодовое слово» при первом переходе. Отметка входа живёт в localStorage
   сайта и переживает обновления гида.
4. **Офлайн**: кэшируй реестр и манифесты (HTTP cache + своя обёртка);
   без сети показывай последний кэш с пометкой даты, ссылки открываются
   только для уже закэшированных страниц. Манифесты маленькие (~10 КБ) —
   обновляй при каждом входе в раздел.
5. **Обновления**: у манифеста есть `build.commit` и `build.utc` —
   показывай «обновлён …», подсвечивай гид, если commit изменился с
   прошлого просмотра.

## Ограничения

- Никакого парсинга HTML гида — только оба JSON.
- Личных данных в реестре и манифесте нет; билеты и коды броней туда
  не попадают никогда.
- Ошибки сети/404/битый JSON — дружелюбные состояния, не crash.
- Новый гид появляется в приложении добавлением записи в реестр —
  код приложения не меняется (проверь на тестовой второй записи с
  несуществующим URL: карточка должна показать состояние ошибки и не
  ломать список).

## Критерии приёмки

- Реестр загружается, гид «Япония 2027» виден с датами 02–10.09.2027.
- Манифест парсится: 9 дней, 25 аудиотреков, 6 файлов комплекта.
- «Открыть день» ведёт на `<url><page>` и открывается страница после
  ввода кодового слова.
- Ссылка на mp3 отдаёт `audio/mp3` и воспроизводится.
- Повторный запуск без сети: список и карточка из кэша, пометка даты
  кэша, живые ссылки честно отключены.
- Юнит-тесты парсеров обоих схем на образцах выше + тест на битый JSON.
