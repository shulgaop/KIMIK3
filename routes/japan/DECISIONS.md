**D-001** · 2026-11-22 · `подтверждено`
Публикация: GitHub Pages из приватного репозитория + парольный экран (клиентская
проверка кодового слова) в гиде.
Причина: пользователь требует GitHub и приватность; приватный Pages с контролем
доступа существует только в GitHub Enterprise Cloud.
Альтернативы: (B) приватная публикация через Kimi `webapp-publish` — отклонена
пользователем; (C) публичный Pages — отклонён.
Следствия: нужен GitHub Pro на этапе публикации; парольный экран — защита «от
случайных глаз», не криптография; личные данные в гид не включаются в любом случае.

**D-002** · 2026-11-22 · `подтверждено`
Маршрут на 9 дней (02–10.09.2027) с 3-дневным классическим ядром Накахэти
(Такидзири → Цугизакура → Хонгу → Нати) вместо полного 5-дневного трека.
Причина: окно поездки 9 дней не вмещает полный трек с Фудзи и городами.
Альтернатива: полный 5-дневный Накахэти — не помещается в даты.

**D-003** · 2026-11-22 · `предложено`
Файлы управления японским проектом хранятся в `routes/japan/` (CONTEXT, DECISIONS,
TASKS, SOURCES), а не в корне репозитория.
Причина: корневые `AGENTS.md`, `README.md` и документы принадлежат маршруту
Фанских гор и репозиторию в целом; смешение создало бы дубли и конфликты
соглашений. Atlas общий и остаётся в корне.
Альтернатива: управление в корне — отклонена как риск для маршрута Фанов.
