# Форма отчёта для Wikiloc — шаблон

Универсальная форма публикации трека на wikiloc.com. Заполняется после
прохождения; блоки `[ПО ФАКТУ]` — только реальные наблюдения с маршрута,
без домыслов. Заполненный пример — `routes/japan/generated/викилок/`.

## Что подготовить до загрузки

- [ ] GPX трека (один файл = одна публикация; многодневку делить по дням)
- [ ] 5–15 фото по ходу трека (горизонтальные, до 8 МБ каждое)
- [ ] Чистое ходовое время и дата прохождения
- [ ] Заметки о воде, навигации, опасных местах по факту

## Поля формы Wikiloc

| Поле | Что вписать |
|---|---|
| Название | До ~100 знаков: регион — суть — тип («Кумано Кодо: Такидзири → Цугизакура (Накахэти, день 1)») |
| Активность | Пеший туризм (Hiking) |
| Сложность | Лёгкий / Средний / Сложный / Очень сложный — по худшему участку, не по среднему |
| Тип | Кольцо / Туда-обратно / Точка-точка |
| Дистанция, набор | НЕ заполнять руками — Wikiloc считает из GPX; проверить и упомянуть в описании, если расчёт отличается |
| Видимость | Публичный (или Приватный — трек виден только по ссылке) |
| Описание | Plain text — **разметка не работает**: без `**`, `#`, таблиц. Структура — заголовки-строки как ниже |

## Текст описания (шаблон, plain text)

```
[ОБЗОР — 2–3 предложения: где это, зачем идти, главная награда дня.]

ДИСТАНЦИЯ И ВРЕМЯ: XX км, набор +XXX м / сброс −XXX м. Чистое ходовое
время [ПО ФАКТУ] X ч XX мин; с остановками и фото — X ч.

КАК ДОБРАТЬСЯ: [старт: транспорт, остановка, парковка; финиш: куда
уходят автобусы/поезда, частота].

НАВИГАЦИЯ: [разметка тропы, указатели, где сверяться с треком; есть ли
связь/офлайн-карты].

ВОДА И ЕДА: [источники воды по км, магазины, вендинг; что нести с собой].

ПОКРЫТИЕ И ОБУВЬ: [лесная тропа / каменная мостовая / асфальт;
скользко после дождя — да/нет].

СЕЗОН: [когда ходить, когда не ходить и почему].

ОПАСНОСТИ: [реальные: крутые спуски, тайфуны, сугибоку, клещи —
только то, что подтверждено или замечено].

ИНТЕРЕСНОЕ НА МАРШРУТЕ: [3–5 фактов по точкам: история, природа,
культура — то, ради чего идти].

ПРОЙДЕНО: [дата], компания [N чел.], погода [ПО ФАКТУ].
```

## Точки (waypoints) — таблица к заполнению

Wikiloc позволяет добавить точки с фото и подписями; 5–10 самых
говорящих достаточно.

| № | Название | Широта | Долгота | Высота, м | Подпись/фото |
|---|----------|--------|---------|-----------|--------------|
| 1 | Старт (название) | | | | |
| 2 | | | | | |
| … | | | | | |
| N | Финиш (название) | | | | |

## Чек-лист перед нажатием «Опубликовать»

- [ ] Трек на карте совпадает с пройденным (без «полётов» GPS — обрезать)
- [ ] Название содержит регион — так трек находят в поиске
- [ ] Сложность не занижена; опасные места названы в описании
- [ ] Координаты стоянок/воды — только фактические, не «по карте»
- [ ] Фото не содержат лиц посторонних и личных данных (билеты, документы)
- [ ] Дата прохождения и чистое время заполнены — это главное, что ищут
  в чужих отчётах
